# 明日预测模型历史滚动回测报告

报告日期：2026-08-18  
模型版本：`ensemble-v2.0`  
随机种子：`20260818`

## 结论摘要

当前模型在近期窗口出现轻微方向优势，但在更宽的时间窗口中消失，尚不能证明具有可用于投资决策的稳定预测能力。

- 近期面板：59 只股票、2,360 条预测，方向胜率 52.16%，按股票聚类 Bootstrap 95% 区间为 49.87%–54.24%。相对滚动多数方向基准仅提升 0.59 个百分点，提升区间为 -1.53–2.76 个百分点。
- 宽时间面板：59 只股票、2,360 条预测，方向胜率 49.75%，95% 区间为 47.97%–51.61%；相对滚动多数方向基准低 0.08 个百分点。
- 两个面板的 Brier 分数分别为 0.2576 和 0.2629，均差于只预测样本自然上涨率的常数基准 0.2493 和 0.2492。
- 高置信阈值在运行前固定为上涨概率不高于 42% 或不低于 58%。近期面板胜率 52.97%，宽时间面板只有 48.29%，未形成稳定的选择性优势。
- 宽时间面板中，ML 门控开启的 204 条预测胜率为 46.57%，关闭的 2,156 条为 50.05%；当前门控没有带来外部样本优势。
- 预期收益方向胜率在近期和宽时间面板分别只有 49.24% 和 48.86%，当前不应作为止盈、止损或仓位变化的主要依据。

## 回测设计

股票池来自中证指数公司 2026-08-18 发布的沪深300成分表。沪深300由 300 只规模大、流动性好的代表性证券组成，因此本报告结论适用于大盘高流动性 A 股，不代表全部 A 股。

- 从 300 只股票中用固定种子无放回抽取 60 只。
- 59 只取得至少 180 根历史日 K；中国铀业（001280）只有 172 根，按预设规则剔除。
- 每个历史预测切片只向模型传入切片日及以前的个股前复权日 K 和同期沪深300日 K，预测下一根实际日 K，避免未来 K 线泄漏。
- 使用线上同一入口 `buildNextDayPrediction`，参数固定为 126 日窗口、15 个相似日、A 股市场和沪深300基准，不另写近似预测逻辑。
- 近期面板每隔 3 个交易日取一个预测时点，共 40 个时点/股票，覆盖 2026-02-04 至 2026-08-17。
- 宽时间面板每隔 10 个交易日取一个预测时点，共 40 个时点/股票，覆盖 2024-12-20 至 2026-08-17。
- 新闻未纳入：当前没有能够按历史发布时间完整重建的新闻归档，强行使用今天可见新闻会造成未来信息泄漏。
- 日 K 数据无法无偏复原盘中任意时刻的实时 OHLCV，因此本报告只验证“收盘预测下一交易日”，不冒充盘中模式回测。

## 发现

### 1. 概率明显过度自信

宽时间面板中，模型给出低于 35% 上涨概率的 310 条预测，实际上涨率却为 51.94%；给出 58%–65% 的 300 条预测，实际上涨率只有 49.33%。整体平均概率看似接近自然上涨率，但概率分桶不单调，不能把 65% 直接解释为接近 65% 的历史命中率。

在 2025 年数据拟合一维 Platt 校准并在 2026 年留出集验证后，Brier 从 0.2607 降至 0.2513，但胜率仅从 50.23% 变为 50.57%，与只输出训练期自然上涨率的常数模型几乎相同。校准可以降低误导性的确定感，但不能凭空创造预测优势。

### 2. “高置信”和等级没有形成可靠排序

近期面板中看跌高置信信号胜率为 54.50%，但宽时间面板跌到 46.42%；看涨高置信信号分别为 49.88% 和 51.81%。宽时间面板中的 C/B/A 等级胜率分别为 46.40%、52.96%、47.17%，没有随等级提高而单调增加。当前 `decisionConfidence` 和 S/A/B/C 更接近启发式评分，不是经外部样本校准的命中率。

### 3. 内部 ML 门控不能替代真正的外部验证

ML 只在约 9% 的预测中开启，但近期和宽时间面板的开启组都没有超过关闭组。将现有概率、预期收益、市场状态、等级和置信度再输入一个轻量正则 Logistic 元模型，虽然在 2025 年验证段表现改善，但在完全留出的 2026 年样本中胜率降到 46.04%，表现出明显的时间漂移和过拟合。当前瓶颈首先是点时数据、标签和跨时间验证，而不是模型复杂度。

### 4. 个股与时间稳定性不足

宽时间面板的单股胜率中位数为 47.5%，四分位区间为 45.0%–55.0%；只有 21/59 只超过 50%，24/59 只超过各自滚动多数方向基准。月度胜率在主要月份间约为 37.6%–57.1%，说明模型边际会随市场环境显著漂移。不能根据本次回测中少数高胜率个股直接建立白名单，否则会产生选择偏差。

## 优化优先级

### P0：先修复可信度和发布门槛

1. 将当前预测标记为研究/观察信号。在新的外部样本门槛通过前，不用“高胜率”或“高置信”措辞驱动止盈、止损和仓位决策。
2. 对概率增加独立的时间外校准层，按滚动窗口进行 Platt、Beta 或 Isotonic 校准；当校准层只学到常数概率时，应允许模型明确输出“无优势/暂不决策”。
3. 暂停 ML 权重和预期收益回归对最终决策的正向加成，直到其在完全留出的日期区间同时改善方向胜率、Brier 和校准误差。
4. 把 S/A/B/C 改为经验可靠性等级：等级由历史覆盖率、相对基准提升和置信区间下界决定，不再由启发式分数直接映射。

### P1：重建轻量 ML 和特征体系

1. 使用跨股票面板训练轻量模型，而不是每只股票只用约 126 条样本独立训练。首选正则 Logistic 作为透明基线，再以小型 LightGBM/HistGradientBoosting 作为挑战者；线上只需要加载系数或小模型，推理仍然很轻。
2. 验证按日期切分，并使用 Walk Forward + purge/embargo；同一天所有股票必须位于同一折，禁止随机拆分造成横截面泄漏。
3. 增加严格点时的横截面特征：全市场涨跌家数、涨停/跌停家数、行业相对强弱、市场成交额和波动率、个股在行业内的强弱分位。大盘走势应作为可交互的状态变量，不应只写成固定利好/利空叙事。
4. A 股开盘前预测“今日”时，可以使用当时已经收盘的上一夜美股；A 股收盘预测“明日”时，只能使用当时已经可见的最近一次美股收盘，不能使用随后才发生的美国交易时段。
5. 新闻因子需要建立 `published_at`、首次抓取时间、来源、标的映射和事件去重的历史归档。训练和回测只读取切片时点前已出现的新闻，并把影响限制为小权重，直到独立消融实验确认增益。

### P2：建立持续学习闭环

1. 每次线上预测保存不可变的模型版本、特征快照、概率、基准值和数据截止时间；下一交易日收盘后自动写入真实标签。
2. 每日更新监控，至少包含 Accuracy、AUC、Brier、ECE、覆盖率、相对基准提升，并按市场状态、行业、股票和预测模式分层。
3. 每月进行 Champion/Challenger 重训和影子评估，不让新模型直接替换线上模型。建议发布门槛至少包括：股票聚类 95% 区间的相对基准提升下界大于 0、Brier 优于自然上涨率和滚动概率基准、ECE 不高于 3%、高置信信号在足够覆盖率下仍有稳定提升。
4. 扩展到历史成分股、退市股票和更完整的 A 股股票池，处理停牌、涨跌停、上市时长、复权和幸存者偏差；最终再加入交易成本和不能自由做空的决策效用评估。

## 复现

回测脚本：`web/scripts/backtest-next-day-prediction.mjs`

中证指数公司成分表下载地址：

`https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/file/autofile/cons/000300cons.xls`

将官方 XLS 转成 CSV 后运行：

```bash
cd web
NODE_NO_WARNINGS=1 node --experimental-strip-types scripts/backtest-next-day-prediction.mjs \
  --universe /path/to/000300cons.csv \
  --output /tmp/prediction-backtest.json \
  --stocks 60 --minimum-stocks 50 --days 650 \
  --origins 40 --origin-step 10 --minimum-history 180 \
  --seed 20260818 --workers 4 --bootstrap-samples 2000
```

本报告是模型评估，不构成投资建议或收益承诺。
