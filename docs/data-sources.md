# 数据来源、限制与合规边界

TrendSight 使用公开可访问的数据接口，不附带任何第三方历史行情、新闻或财务数据，也不提供第三方服务的可用性保证。

美股代码检索、日 K、延时报价与新闻由独立的新浪美股/搜索客户端获取；财务数据来自美国 SEC Company Facts。SEC Company Facts 以公司申报口径为准，不提供实时机构持仓；美股延时报价当前也不提供五档委托和分钟 K 线。所有美股金额均按 USD 展示，不与 CNY 自动合并。

生产部署建议通过 `SEC_USER_AGENT` 设置符合 SEC 要求的应用名和联系邮箱；未配置时使用项目默认标识。

## 数据来源

| 类别 | 当前用途 |
| --- | --- |
| 新浪财经公开数据 | 前复权因子、实时/历史行情和新闻检索；A 股日 K 成交量按股解析 |
| 东方财富、腾讯公开数据 | 证券简称、估值、分红、财务报表和带自动降级的当前交易日 Level-1 成交明细；腾讯实时行情的流通 A 股本用于计算最新交易日换手率并交叉校验成交量单位 |
| 搜狐财经公开数据 | 上证指数日 K，以及上证与深证综指成交额按交易日求和得到的沪深两市成交额 |
| Cloudflare D1 | 研究状态和匿名聚合遥测 |

浏览器只访问同域 `/api/*` 路由；具体上游接口由 `web/app/lib` 中的服务端客户端模块封装，可能随数据提供方调整而变化。

## 已知限制

- 免费接口可能限流、要求验证、改变字段或临时不可用。
- 历史行情是日 K 聚合数据，不包含逐笔委托、撤单和订单链路。
- 历史行情只对腾讯行情中存在同日流通 A 股本的最新交易日计算换手率；不会用当前股本反推全部历史交易日。
- 单日成交下载是约 3 秒聚合的 Level-1 明细；一行可能包含多笔真实成交，不等同于交易所 Level-2 原始逐笔订单。
- 新闻搜索结果可能遗漏、重复、延迟或相关性不足。
- 财务规则和技术信号是研究辅助，不能检测所有会计问题，也不能预测收益。
- 名称检索和主要行情研究范围以沪深 A 股为主。

## 使用边界

- 遵守数据提供方条款、robots 规则、访问频率限制和所在地法律法规。
- 不要使用本项目绕过登录、验证码、访问控制、付费墙或授权限制。
- 对外分发抓取结果前，确认你拥有存储和再分发这些数据的权利。
- 商业、生产或高频场景应接入有明确授权、稳定性承诺和数据质量责任的数据服务。

## 隐私

- 浏览器存储可包含最近查询、标注和视图偏好；共享设备上请主动清理。
- 托管环境以邮箱的 SHA-256 派生值作为用户键，不把邮箱原文写入 D1。
- 匿名遥测只记录白名单事件的每日总次数和总耗时，不记录查询股票或研究内容。

## 投资风险

所有“主力行为”、B/S 指引、新闻情绪、财务异常和回测结果都是模型或规则代理。它们可能受到样本偏差、未来函数、复权口径、数据缺失、交易成本和市场制度变化影响。使用者应自行验证并承担决策风险。
