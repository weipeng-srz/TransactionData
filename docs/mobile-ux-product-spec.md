# TrendSight 手机体验优化产品说明

日期：2026-10-13。需求范围：手机端操作体验；覆盖 [功能地图](code-map.md) 的 F01–F13。本文与 [测试方案](mobile-ux-test-plan.md) 一一对应，执行结果由 [验收记录](mobile-ux-acceptance.md) 保存。

## 目标与边界

用户优先需求：手机 banner 的常驻搜索框收为放大镜；下滚时收起完整 banner，显示包含个人头像、搜索按钮及页面链接的精简栏；回到顶部恢复完整 banner。所有新增布局规则限于 `max-width: 820px`，821px 及以上沿用桌面界面。页面路由、证券身份、查询流程、行情计算、账户权限与数据持久化语义不改变。

本轮按“源码审核提出改进 → 研发实现 → 测试发现问题后立即修复 → 产品复核”推进。下表恰好 50 项，是待实现及验收的产品要求，不代表 50 个已在真实手机上复现的缺陷。现有界面已具备的 44px 点击区域、16px 输入字号和部分单列布局不单独计为新改进；每项列出更具体的现状依据。

## 证据口径

- **S：源码审核**，已阅读实际组件/CSS 和 F01–F13 研究地图，能确定布局规则或交互缺口；不能据此宣称真实浏览器通过。
- **B：浏览器实测**，必须记录 URL、身份、视口、操作、可观察结果；空态只证明空态，模拟数据只证明界面契约。
- **A：自动验证**，构建、测试或 CSS/DOM 断言；源码正则只能证明规则存在，不能替代视觉或完整操作链验收。
- 初始清单的依据均为 S；浏览器与自动化的实际通过范围以验收记录为准。产品最终结论必须写明尚未完成的真实设备、上游或持久化检查。

## 产品最终复核（本地交付范围）

2026-10-13，产品核对50项需求到具体实现的映射，并复核研发、独立测试及产品浏览器证据。补验前进一步发现旧 ResearchDock 已不在实际页面挂载，已将M26/M27纠正为真实 ReviewEditor 与 StockReviewEntry 入口，撤回旧组件的本轮样式改动，并完成真实入口浏览器复验。两处功能地图同步纠正，避免把旧组件单测当成当前页面可见证据。**本轮手机改动在已执行的本地工程检查和浏览器范围内通过；不将其表述为50项在全部真机和数据状态下均已验收。** 逐项结果、缺陷修复与最终测试数量以 [验收记录](mobile-ux-acceptance.md) 为准。

已确认的核心结果：390px默认搜索收为图标，展开后可搜索AAPL并进入美股页面；滚动后精简栏包含账户、搜索和页面导航，研究子导航与其保留约8px间隔。320px账户页展开搜索得到平安银行 `000001/CN` 候选，面板位于(21,123)、尺寸278×256；按Escape关闭后焦点回到“搜索股票”，页面宽度仍为320px。收起/恢复阈值、输入法、异步取消及焦点路径另有组件行为测试覆盖。

桌面边界复核：820px为手机布局，banner高108px、输入隐藏且搜索图标可见；821px与1024px恢复原桌面输入，banner高126px；1440px banner高68px，桌面搜索保留且AAPL查询可进入 `US:AAPL`。这些视口测得页面scrollWidth均与视口一致。新增非banner规则已核对仅作用于≤820px；没有保存改动前所有桌面页面的逐像素快照，因此这里确认断点隔离及已检查操作，不能宣称全站像素完全相同。

滚动补验：390px从滚动844px的精简栏回到0，banner从58px恢复108px且 `compact=false`，AAPL输入仍正常；1440px滚动321px后banner保持68px且不进入精简状态。测试发现180ms过渡期间子导航可能短暂叠压，修复为同步过渡后，在同一次浏览器调用中采样14个时点，banner底部与子导航顶部始终相差8px，回顶后子导航恢复文档流。证据：[顶部](assets/mobile-ux-2026-10-13/top-390.jpg)、[精简栏](assets/mobile-ux-2026-10-13/compact-390.jpg)、[搜索](assets/mobile-ux-2026-10-13/search-390.jpg)、[桌面](assets/mobile-ux-2026-10-13/desktop-1440.jpg)。

独立产品体验了390px的选股候选/详情/交易计划、全球概览/区域/等比地图、复盘弹窗/章节/保存区。选股抽屉末内容和底操作可达，地图保持约1.972比例；复盘17个相关控件实测44px。账户页由主研发补验：390px资料保存与密码更新按钮均约316px宽、44.2px高。复盘关闭时出现浏览器工具超时，不能将该次操作记为通过或据此认定应用故障。
