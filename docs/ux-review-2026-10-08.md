# TrendSight UX 改进与验收记录

日期：2026-10-08。验收结论：**本轮优化通过**。

范围为首页导航与首次使用引导、全站股票搜索、手机布局和相关键盘交互。使用本地运行版本，由主代理实际操作浏览器、研发代理实施搜索修复、独立测试代理运行自动化检查、独立 UX 代理审阅代码和截图。此结论是本轮改动的本地验收，尚未部署线上。

## 体验发现与落实

| 问题 | 建议与改进 | 验收结果 |
| --- | --- | --- |
| 手机导航挤压搜索，结果按钮逐字换行 | ≤820px 改为两行：品牌/导航/主题在第一行，全宽搜索在第二行；同步固定导航占位 | 390px 下输入从约 88px 增至 284px，结果卡宽 346px；两按钮各为 160×44px |
| 桌面首页很长，寻找自选列表需要连续滚动 | 增加可见页标题，以及常驻的收益概览、决策工作台、自选与持仓章节入口 | 点击直达对应区域；焦点移至目标区域；内容没有被导航遮挡 |
| 首访默认组合概览缺少明确行动入口 | 在空组合前置“从一只关注的股票开始”，按钮直接聚焦搜索 | 手机首屏可见；添加首只股票后引导消失 |
| 自动搜索失败静默，关闭后可能被晚到请求重新打开 | 增加搜索中、失败、添加/打开反馈；取消旧请求并检查取消状态；支持 Esc、点击外部和离开表单关闭 | 无匹配时显示可读提示；快速改词只显示最新结果；关闭后不重新弹出 |
| 搜索结果键盘操作不完整 | 输入框关联非模态结果面板；Tab 或 ↓ 到达查看/添加按钮；Esc 回到输入 | 实际键盘操作通过；空输入禁用提交和添加 |
| 持仓弹窗被全局搜索快捷键抢焦点 | 有可见模态弹窗时阻止 Cmd/Ctrl+K 的浏览器默认行为并保留焦点；增加输入法组合状态保护 | Cmd+K、Ctrl+K 后焦点仍在弹窗；Tab 循环、Esc 返回原编辑按钮 |

保持原有视觉语言，以清晰的中文标题、紧凑间距、明显焦点和足够的触控面积改善阅读与操作。没有更改行情、评分、信号和持仓计算规则。

## 回修闭环

1. 基线 lint 和构建通过，测试 274/278 通过。4 个既有失败来自固定在 2026-08-25 的夹具配合真实系统时间，触发行情过期守卫。仅在对应测试中 mock `Date.now()`，测试结束自动恢复，保留产品过期保护。
2. 独立 UX 首轮复核发现合法单字母美股代码（F/T/A）被“两字符起搜”限制挡住，手机无法从结果添加。研发放行合法美股代码；浏览器复测 `F` 返回“福特汽车 / F · 美股”及添加按钮。
3. 自动化验收发现新页头英文标注为 10px，低于项目 11px 下限，修正为 11px。同步旧版单行导航的布局断言；仅允许取消请求路径重新抛出原异常，普通失败仍必须映射为公共错误文案。
4. 全量 lint、构建与 278 项测试通过。最后补齐模态弹窗中的快捷键默认行为保护后，重新通过定向 ESLint、TypeScript、生产构建和浏览器焦点复测。
5. 独立 UX 审阅手机浅色、手机深色和桌面截图，并结合操作记录，最终签收：本轮无阻断问题。独立 QA 签收自动化检查与源码复核。

## 浏览器验收

使用 Codex 内置浏览器，访问 `localhost:3000`；首次使用和添加测试使用独立的 IPv6 本地源 `[::1]:3000`，保留原 localhost 下的自选和持仓。

| 场景 | 证据 / 结果 |
| --- | --- |
| 320px、390px、1440px 布局 | 对应页面 `scrollWidth` 等于视口宽度，无整页水平溢出 |
| 手机搜索结果 | 名称、市场、代码清晰可读；查看/添加按钮保持 44px 高度，320px 也无逐字换行 |
| 首访引导 | 点击“搜索第一只股票”后，焦点为 `site-stock-search-portfolio` |
| 添加自选 | 添加 AAPL 后提示成功；空态引导消失；自选列表出现苹果，刷新后仍存在 |
| 搜索输入 | AAPL 快速改为 MSFT 后只展示微软；单字母 F 返回福特汽车 |
| 错误反馈 | 不存在的名称显示“没有找到匹配的 A 股或美股，请检查名称或代码” |
| 关闭结果 | Esc 关闭并回输入；输入后立即 Esc，经过后续操作仍未重开；点击外部也关闭 |
| 模态框 | Cmd+K、Ctrl+K 保持模态内焦点；末项 Tab 循环到关闭按钮；Esc 返回原编辑按钮，未保存测试持仓 |
| 个股流程 | 搜索 AAPL/600519 可进入分析；基础视图、专业视图及 K 线章节可切换 |
| 全站导航 | 自选 → 个股 → 全球 → 选股 → 自选均可到达；390px 全球和选股页不被新导航遮挡 |
| 外观 | 浅色与深色搜索结果可读，已保存截图 |

自动化测试包含既有 API、数据与布局回归。真实浏览器未进行上游故障注入、物理手机软键盘或屏幕阅读器验证；输入法保护已做代码与类型检查。这些不作为已验证能力宣称。

本轮产品文件：

- `web/app/components/SiteBanner.tsx`
- `web/app/components/SiteBanner.module.css`
- `web/app/components/PortfolioHome.tsx`
- `web/app/components/PortfolioHome.module.css`

测试维护涉及 `mobile-layout.test.mjs`、`card-control-layout.test.mjs`、`ux-release-guardrails.test.mjs` 和 `portfolio-workbench.test.mjs`。

修改前已执行 GitNexus upstream impact：`SiteBanner`、`PortfolioHome`、`openStock`、`addStock`、`resolveStock`、`handleShortcut`、`timer`、`lookupStock` 均为 LOW，最多 2 个直接调用方。React 组件跨页面复用额外通过四个页面入口验收覆盖。

最终 `detect_changes` 对整个工作区报告 14 个文件、53 个符号、18 个流程、CRITICAL；其中包含任务开始前已有的研究算法等改动。相对 `main` 的比较报告 77 个文件、760 个符号、146 个流程、CRITICAL，包含历史分支差异。这两个总量不能作为本次 UX 改动的独立风险等级；原有改动均保留，未提交或发布。
