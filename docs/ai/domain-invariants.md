# AI 必须保留的领域约束

本页提炼当前实现中最容易被“局部修复”破坏的语义。它是代码变更检查入口，不能替代源码；对应功能编号和测试入口见[功能研究地图](../feature-research-map.md)。修改这些语义时，必须同步生产者、消费者、兼容逻辑、测试和专题文档，记录有意变化及迁移方式。

## 证券身份与组合边界（F01 / F06）

- [security.ts](../../web/app/lib/security.ts) 是市场/币种/证券键入口：旧记录缺省 CN/CNY；美股规范化大写，路由与持仓键使用 `US:<SYMBOL>`。不要仅用裸 ticker 或名称关联跨市场数据。
- [watchlist.ts](../../web/app/lib/watchlist.ts) 的 `buildPortfolioStocks` 取自选与持仓的并集。移除自选不删除持仓，自选 50 条限制不应用于独立持仓，交集不得重复计数。
- 原始金额按 CNY/USD 分组。首页通过 `convertPortfolioTotalsToCny` 和明确展示、可编辑的 USD/CNY 汇率额外生成人民币总计；只影响展示，不改写成本/持仓。收益日历、复盘和风险敞口保留原币语义，不隐式相加。

## 数据级别、价格和缺失值（F02 / F03 / F07）

- [数据格式](../data-formats.md) 的 `#META/#DAY` 是解析契约。日 K OHLC 四点是合成代理；公开 Level-1 成交切片也不等于交易所 Level-2 逐笔订单。
- 原始成交/持仓成本与前复权图表价格不能直接比较。[holdingRisk.ts](../../web/app/lib/holdingRisk.ts) 通过明确的当日复权因子转换；未知/后复权口径或因子无效时返回不可用，不猜价格。
- 最新换手率需要同日流通股本，不能用当前股本回填全部历史。美股上游未提供的五档、分钟线、机构持仓不得伪造。
- `null`、空数组、加载中、失败与真实零值不同；展示不可用原因，不能用默认零值生成收益、比率、胜率或看似完整的行情。

## 时钟、交易日与完整日线（F02 / F03 / F07 / F11）

- [portfolioEarnings.ts](../../web/app/lib/portfolioEarnings.ts) 用上海/纽约时区计算 CNY/USD 市场日。不要以浏览器所在日期或 UTC 日期统一切日。
- 区分报价日期/时间与 `fetchedAt`。美股延时报价的抓取时钟不是交易所成交时间；[useReviewQuotes.ts](../../web/app/features/review/useReviewQuotes.ts) 明确展示延迟与获取时间。
- [realtimeDailyCandle.ts](../../web/app/lib/realtimeDailyCandle.ts) 与 [closedMarketDay.ts](../../web/app/lib/closedMarketDay.ts) 只把匹配证券、有效日期和交易时段的快照用于当天日线；盘中临时日线不能冒充已完成日线。
- 持仓参考线仅基于完整日 K，盘中报价不应移动止盈止损线；收益日历不回填未观察日，同日持仓变化使当日估算失效，旧报价不能重复记入新的一天。
- 全球市场的当地时段判断及美股收益日检查有各自数据门槛，不代表已实现完整交易所节假日服务。ETF/期货扩展时段代理与现货指数收盘必须分开标识。

## 财务口径与可比性（F04）

- [financialAnalysis.ts](../../web/app/lib/financialAnalysis.ts)：利润/现金流累计值拆单季，TTM 依赖连续季度；资产负债表保持期末余额，不能按流量累加。
- 保留 `reportDate`、`noticeDate` 与估值快照日期的区别；[usStockFinancials.ts](../../web/app/lib/usStockFinancials.ts) 按公司财政年度 FY 及 SEC 申报拆季度，不能强制映射为自然年 A 股口径。
- 缺少季度/字段时保留缺失，不补零凑 TTM。亏损期现金覆盖率、金融行业可比性、薄净资产 ROE 都有专门判断，不可仅因数值为正就显示“健康”。
- 当前财务快照和最新修订申报不天然构成历史时点可得数据。若将其加入历史预测/回测，需另行验证披露日期及版本，不能声称现有行情防泄漏检查已覆盖财务。

## 预测、信号与回测时间边界（F08 / F10）

- [nextDayPrediction.ts](../../web/app/lib/nextDayPrediction.ts) 的 `today` 模式剔除目标日 K 线；无实时快照时把最后一根日 K 作为检验目标。今日行情用于检验/风控，不能进入今日预测特征。
- `tomorrow` 可以使用有效的当前时段快照，必须保留 `isPartialSession`、时间与成交量投影口径；训练样本标签不能使用尚未完成的目标日。
- 滚动验证仅使用当前验证行之前的训练样本；跨股票面板模型仅用于训练截止日之后、带基准的 A 股完整收盘切片。面板与 regime 校准有独立截止日，不能只检查其中一个。
- 基准按当前日或更早日期查找；预测新闻排除截止日之后的条目。这是现有**日期级**约束，不等于已经实现逐时新闻可得性或完整 point-in-time 数据库。
- [research.ts](../../web/app/lib/research.ts) 采用信号后一根开盘成交，计入成本及可识别的成交限制；A 股退出遵守 T+1。受阻退出顺延、未退出单列，不能剔除失败交易改善统计；开盘退出不能再使用该日后续高低价。
- 保持追加未来 K 线不改变已确认历史信号。评分、选股规则置信度、统计概率与验证指标是不同量，不能互换标签；“主力/吸筹”标签不证明真实账户身份。
- 旧 `web/reports/` 结果只对记录的输入、版本和参数有效；模型变化后需生成新证据，不能复用旧表现作为当前验证。

## 持仓估算与复盘实绩（F07 / F12）

- 收益日历使用持仓数量 ×（当前价 − 昨收），属于观测估算；持仓成本盈亏、当日估算和已实现交易净盈亏是三种不同指标。
- [tradingJournal.ts](../../web/app/lib/tradingJournal.ts) 的 `operationPrice` 独立于成交入场/平仓价；操作后涨跌衡量标的变化，卖出后上涨仍是标的上涨。
- 实际净盈亏要求完整平仓、有效日期和已知费用；未知费用不是零，观察记录/未平仓不计已实现收益。复盘日期校验当前使用北京时间，不能擅自套用收益日历切日语义。
- 规则执行率仅统计已完成复盘中的遵守/违反；待评价、不适用、草稿不入分母。策略名称及规则文本/版本保留历史快照，编辑规则不能重写历史。
- 备份合并按 ID 保留已有冲突记录；未知版本、损坏数据明确报错，不通过清空历史“恢复”。草稿允许中间输入，正式保存需要业务校验及数据库确认。

## 账户隔离、并发和失败恢复（F09 / F12 / F13）

- [accountStorage.ts](../../web/app/lib/accountStorage.ts) 是内存 facade，个人数据持久化唯一入口是账户数据库；不要新增共享 `localStorage` 旁路。公开行情 Cache API 是另一种只读缓存，不能存放个人研究数据。
- 身份来自数据库会话；请求中的 userId 仅用来校验当前账号，不能授予访问权限。先确认会话并 hydrate，再挂载个人功能；切号/退出清理状态，旧异步响应不得污染新账号。
- [account-data/route.ts](../../web/app/api/account-data/route.ts) 按 `user_key + key` 隔离，更新再匹配 `revision`；新建 revision=0，删除写入 `value=null` 并保留版本，不能删掉版本约束。
- 同一写入的响应丢失后必须用原 `mutationId` 与原值重试；后续编辑等待它解决。409 保留待写编辑并要求重载合并，不能自动采用“最后写入覆盖”。
- 保存失败保留内存待写数据并提供重试/导出；数据入队或 UI 乐观更新不等于数据库已确认。账户数据键有白名单，单值为 2 MiB 上限，新增键/格式需要同步协议与兼容测试。
- 旧 `/api/research-state` 仅作兼容链路；旧数据清理和并发保存同样不能跨用户或覆盖新状态。遥测只允许白名单聚合事件，不记录 cookie、密码、证券查询或研究正文。
